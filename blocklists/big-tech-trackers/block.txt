# Block Big Tech trackers: what is blocked.
#
# The companies are the ones on Beyond's tech fines tracker (gobeyond.nz/tech-fines): Alphabet, Apple, Meta, Amazon,
# Microsoft, ByteDance and X. Only their advertising, tracking and telemetry addresses are here, never the ones their
# products or Beyond's own products need to work. Those are in allow.txt, and tests/trackers.test.mjs checks that
# nothing here blocks anything there.
#
# One domain per line. A domain blocks itself and every name under it. "#" starts a note.
# After a change run: node tools/trackers.mjs

# Alphabet (Google)
doubleclick.net                    # ads and ad measurement across the web
googleadservices.com               # ad clicks and conversions
googlesyndication.com              # AdSense ads on other sites
googletagservices.com              # ad tags
googletagmanager.com               # Tag Manager and gtag.js, which load Google Analytics and ad tags
google-analytics.com               # Google Analytics collection
region1.analytics.google.com       # Google Analytics 4 collection (the dashboard, analytics.google.com, stays)
region1.google-analytics.com       # Google Analytics 4 collection
adservice.google.com               # ad personalisation
adservice.google.co.nz             # ad personalisation, New Zealand
app-measurement.com                # Google Analytics for Firebase, inside phone apps

# Apple

weather-analytics-events.apple.com # Weather analytics
